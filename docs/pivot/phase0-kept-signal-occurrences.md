# Phase 0: kept occurrences of "signal" in user-visible text

The brief allows the words "signal" and "signals" in UI labels when they don't imply a recommendation.
This lists every user-visible line that still contains them after phase 0, as of `pivot/phase0-copy`. Identifiers, CSS
classes, data attributes and console logs are excluded.

The list was generated by scanning text nodes and visible attributes in `public/*.html`, and string literals in
`public/app.js`, `public/manifest.json`, `emailTemplates.js` and `notificationService.js`.

**Why each kept use is acceptable:** they name things or describe the product. That covers nav and page names
("Signals", "Signals history"), record nouns ("unlocked signal", "closed signals", "signal ID"), status words
("Signal expired"), credit mechanics ("signal unlocks") and disclaimers ("Signals do not guarantee profit",
"Every signal can lose"). None of them tells the user to take a trade. Recommendation-style wording was changed
in phase 0: "Signal Found", "Setup Ready", "Unlock Signal", "Ready signals", "Why this signal?", "AI Signal Analyst",
"Gold trading signals" and "Receive signals instantly".
